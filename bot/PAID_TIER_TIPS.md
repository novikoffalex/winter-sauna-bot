# 💳 Рекомендации для платного тарифа Gemini API

## ✅ Статус
Платный тариф активирован, бот работает!

## 💡 Оптимизация расходов

### 1. Настройте лимиты расходов

В Google Cloud Console:
1. Перейдите в **Billing** → **Budgets & alerts**
2. Создайте бюджет для проекта
3. Установите лимит расходов (например, $50/месяц)
4. Настройте уведомления при достижении 50%, 90%, 100%

### 2. Мониторинг использования

Проверяйте использование:
- https://console.cloud.google.com/apis/api/generativelanguage.googleapis.com/metrics
- https://ai.dev/rate-limit

### 3. Оптимизация запросов

**Текущие настройки в коде:**
```php
'maxOutputTokens' => 1024,  // Можно уменьшить до 512 для экономии
'temperature' => 0.7,       // Оптимально для баланса качества/стоимости
```

**Рекомендации:**
- Используйте `gemini-2.0-flash` (быстрее и дешевле, чем Pro)
- Ограничьте длину ответов через `maxOutputTokens`
- Кэшируйте частые вопросы

### 4. Стоимость моделей

**Gemini 2.0 Flash** (текущая модель):
- Входные токены: ~$0.075 за 1M
- Выходные токены: ~$0.30 за 1M
- Быстрая и экономичная модель

**Gemini 2.0 Pro** (если нужна большая точность):
- Входные токены: ~$1.25 за 1M
- Выходные токены: ~$5.00 за 1M
- Дороже, но качественнее

### 5. Экономия на истории разговоров

Текущая реализация сохраняет всю историю. Можно оптимизировать:

```php
// В ConversationStore.php
private $maxMessages = 10; // Вместо 20 - меньше токенов в запросе
```

### 6. Лимиты запросов

С платным тарифом лимиты выше:
- Requests per minute: 360 (вместо 15 на бесплатном)
- Tokens per minute: 1M (вместо 32K на бесплатном)

В Google Cloud Console:
1. **Monitoring** → **Alerting**
2. Создайте алерт на превышение лимитов
3. Настройте уведомления на email

## 🔧 Дополнительные настройки

### Оптимизация промпта

Сократите системный промпт в `LocalizationService.php` - это экономит входные токены.

### Кэширование ответов

Для частых вопросов можно добавить кэш:
```php
// Кэшировать ответы на популярные вопросы
$cacheKey = md5($userMessage);
if ($cached = $cache->get($cacheKey)) {
    return $cached;
}
```
