# Решения проблемы с квотой Gemini API

## Текущая проблема
Превышен лимит запросов к Gemini API на бесплатном тарифе.

## Варианты решения

### Вариант 1: Подождать (бесплатно) ⏰

**Бесплатный тариф Gemini имеет лимиты:**
- Лимиты обновляются каждые 60 секунд
- Обычно нужно подождать 15-60 секунд
- После этого можно снова отправлять запросы

**Что делать:**
1. Подождите 1-2 минуты
2. Попробуйте отправить сообщение снова
3. Лимиты должны восстановиться автоматически

### Вариант 2: Проверить настройки в Google Cloud Console (бесплатно) 🔍

1. Перейдите на https://console.cloud.google.com/
2. Выберите ваш проект (или создайте новый)
3. Перейдите в **APIs & Services** → **Quotas**
4. Найдите **Generative Language API**
5. Проверьте текущие лимиты и использование

**Возможные причины:**
- Не активирован API в проекте
- API не привязан к биллингу (даже для бесплатного тарифа)
- Превышен дневной лимит

### Вариант 3: Активировать API в проекте (бесплатно) ✅

Если API не активирован, нужно:

1. Перейдите на https://console.cloud.google.com/
2. Создайте проект или выберите существующий
3. Перейдите в **APIs & Services** → **Library**
4. Найдите **Generative Language API**
5. Нажмите **Enable** (Включить)
6. Убедитесь, что API ключ привязан к этому проекту

### Вариант 4: Использовать другой API ключ (бесплатно) 🔑

Если у вас несколько проектов:

1. Создайте новый проект в Google Cloud
2. Активируйте Generative Language API
3. Создайте новый API ключ
4. Обновите `GEMINI_API_KEY` в `.env`

### Вариант 5: Оплатить тариф (если нужно больше запросов) 💳

**Google Gemini API Pricing:**
- **Бесплатный тариф**: ограниченные запросы в минуту
- **Платный тариф**: больше запросов, выше лимиты

**Где оплатить:**
1. https://console.cloud.google.com/billing
2. Привяжите платежную карту
3. Настройте лимиты расходов (billing limits)

**Стоимость:**
- Gemini 2.0 Flash: ~$0.075 за 1M входных токенов, ~$0.30 за 1M выходных
- Gemini 2.0 Pro: ~$1.25 за 1M входных токенов, ~$5.00 за 1M выходных

### Вариант 6: Использовать другую модель (бесплатно) 🔄

Попробуйте модель с другими лимитами:

```env
# В .env файле
GEMINI_MODEL=gemini-2.5-flash  # или gemini-1.5-flash-latest
```

### Вариант 7: Добавить задержку между запросами (бесплатно) ⏸️

Можно добавить небольшую задержку в код, чтобы не превышать лимиты:

```php
// В GeminiService.php перед запросом
sleep(1); // Задержка 1 секунда между запросами
```

## Рекомендация

**Для начала попробуйте:**
1. ✅ Подождать 1-2 минуты
2. ✅ Проверить, что API активирован в Google Cloud Console
3. ✅ Убедиться, что API ключ привязан к проекту с активированным API

**Если проблема повторяется:**
- Проверьте лимиты в Google Cloud Console
- Рассмотрите платный тариф, если нужны большие объемы запросов
